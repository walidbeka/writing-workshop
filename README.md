# ورشة كتابة — Premium v3

تمت مراجعة النصوص بالكامل لتكون مصرية واضحة وبدون فلسفة أو جمل تسويقية مبهمة.

## أسلوب الكتابة
- عامية مصرية شيك.
- جمل قصيرة ومباشرة.
- لا وعود مبالغ فيها.
- لا ضغط زائف.
- التركيز على القيمة الحقيقية: المحتوى، التطبيق، المراجعة، ومشروع التخرج.

## Mobile-first
- التصميم متجاوب مع الموبايل أولًا.
- لا يوجد overflow أفقي.
- أزرار الاشتراك بعرض كامل على الموبايل.
- الفيديوهات تتكيف تلقائيًا.
- أحجام الخطوط والمسافات أعيد ضبطها للشاشات الصغيرة.
- الهيدر يتحول إلى نسخة مختصرة على الموبايل.

## ملاحظة مهمة
لو كان أي ادعاء تجاري أو رقم يحتاج إثبات خارجي، راجعه قبل النشر. الأرقام المستخدمة هنا هي المعلومات التي زودت بها صاحب الورشة.
